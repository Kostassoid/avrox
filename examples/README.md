# Examples

This directory contains sample Avro schemas and data plus small applications
that use types generated by `avrox-cli`.

## Contents

- `user-profile.avsc` — a schema covering records, enums, fixed, arrays, maps,
  unions, recursion, defaults, aliases and logical types.
- `user-profiles.jsonl` — human-readable source data for ten user profiles.
- `user-profiles.avro` — the ten profiles written as an Avro data file.
- `rust/` — a standalone Rust application that reads the data file using
  generated, strongly typed structs and then serializes the records back to an
  in-memory Avro file to verify that the round trip preserves every value.
- `go/` — the equivalent standalone Go application, using a self-contained
  generated Avro binary codec and only the Go standard library.

## Regenerating the data file

```sh
cargo run -p avrox-cli -- write --human-readable \
    examples/user-profiles.avro \
    examples/user-profile.avsc \
    examples/user-profiles.jsonl
```

## Rust example

The application lives in its own Cargo workspace and is not a member of the
root workspace.

Regenerate the strong types from the schema:

```sh
cargo run -p avrox-cli -- generate examples/user-profile.avsc \
    --output-file examples/rust/src/generated.rs
```

Run the application, using the default data file:

```sh
cargo run --manifest-path examples/rust/Cargo.toml
```

Or pass a different Avro data file:

```sh
cargo run --manifest-path examples/rust/Cargo.toml -- path/to/file.avro
```

## Go example

The Go module uses only the standard library. Regenerate its profile package:

```sh
cargo run -p avrox-cli -- generate examples/user-profile.avsc \
    --language go --go-package profile \
    --output-file examples/go/profile/user_profile.go
```

Run the tests and application from the repository root:

```sh
go -C examples/go test ./...
go -C examples/go run .
```

Or pass a different Avro object container file (the example supports the
`null` codec used by the included data file):

```sh
go -C examples/go run . path/to/file.avro
```
